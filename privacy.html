プライバシーポリシー

本アプリ（BlueLamp Gmail Personal）は、運営者本人の Google アカウントでのみ使う個人用アプリです。

取得するデータ

運営者本人の Gmail のメール（読み取り・送信・ラベル変更）。Google が許可した範囲（gmail.readonly / gmail.modify / gmail.send）に限ります。

使い方

運営者本人の指示で、メールの検索・下書き・送信を行うためだけに使います。広告・販売・第三者への提供はしません。

Google ユーザーデータの扱い

Google API から受け取った情報の利用と他アプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

取り消し

https://myaccount.google.com/permissions からいつでもアクセス許可を取り消せます。
